# 问题发现记录

针对上游 `330c8e7` / 1.2 的静态观察；未修复，非全面质量验收，也非 OpenCode 特有问题。实际遇到相应路径时据此决定规避、优化或替换。

- 分配输入：`scripts/randomization.py:26–37,69–84` 会截断小数 ratio；n>0 且 block_size 为零或负的合法倍数时可能不终止。使用非空唯一 arms、正整数 ratio 和正且可整除的区组大小。
- 样本对应：同脚本 `89–112` 将序列 strata 汇总排序后重编号，丢失原行身份，缺失标签可能被排除；`115–131` 不拒绝重复 cluster ID，可能给同一簇冲突分配。回填前核对真实样本/簇 ID；字典计数路径不等于样本级映射。
- 设计解释：不完整末区组不保证每层最终严格平衡；`references/randomization_and_blocking.md:63–66` 对分配后协变量的建议缺少处理影响/媒介限制，不能机械调整受处理影响的变量。
- 部署条件：随机分配需 NumPy/Pandas，DOE 另需 pyDOE3；此前检查的解释器缺 pyDOE3，未作本轮环境复查。使用实际技能 scripts 路径；未确认 OpenCode 专有格式障碍。
