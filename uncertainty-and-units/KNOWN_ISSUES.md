# 问题发现记录

针对上游 `330c8e7` / 1.1 的静态观察；未修复，非全面质量验收，也非 OpenCode 特有问题。实际遇到相应路径时据此决定规避、优化或替换。

- 拟合说明：`SKILL.md:133–137` 把 curve_fit 默认重标度说成等于未传 sigma，不适用于一般异方差数据：相对权重仍保留。按真实标准不确定度区分 absolute_sigma 的含义。
- 相关输入：`scripts/propagate_uncertainty.py:223–250` 用 Cholesky，只支持正定相关矩阵，却把失败解释为不存在联合分布；合法奇异正半定矩阵（如完全相关）也会被拒绝。此路径不能据错误消息判数据科学上不可能。
- 已有工具边界：同脚本 `--unit` 只是输出标签，不会统一输入单位；相关 Monte Carlo 当前只支持联合正态。先统一单位，其他分布或奇异相关输入另选适当方法；这些是保留的原工具范围，非 OpenCode 限制。
- 部署条件：数值 CLI 需 Python≥3.12 和 Pint/uncertainties/NumPy/SciPy；静态审计器仅用标准库。未发现 OpenCode 专有部署障碍。
